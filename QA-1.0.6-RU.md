# Проверки VOIDLINE 1.0.6

## Автоматические проверки
- `npm test`: 213/213, без пропусков и ошибок (`tests/regression-1.0.6.txt`). Сохранены сетевые проверки, движение, карты, оружие, профиль и восстановление загрузки.
- `tests/knife-motion-104.test.mjs`: монотонное время, конечные значения, предел двух оборотов, оси Y, неподвижная удерживаемая рукоять, возврат кисти в покой. Требование одного оборота обновлено до двух по новой хореографии.
- `tests/knife-grip-106.test.mjs`: направление обратного хвата, два разных варианта осмотра, открытая конечная поза и малый ход точки контакта.
- `tools/qa-v106-lab.cjs`: по 160 отсчётов для каждого из четырёх клипов и двух вариантов каждого ножа. Нет попаданий вершин ножа в контрольный цилиндр предплечья; нет попаданий клинка и свободной рукояти в контрольный эллипсоид ладони.
- По 120 циклов прерывания `inspect → fire → equip → heavy` для обоих ножей: без накопления смещения и найденных пересечений. Проверен зеркальный хват.
- Геометрические результаты: `tests/knife-clearance-1.0.6.json`. Кадры и четырёхсекундная демонстрация нормальной скорости: `previews/1.0.6-*.png`, `previews/VOIDLINE-1.0.6-knives.mp4`.

## Готовые пакеты
- Linux-клиент и собранный Linux-пакет успешно запущены: `tests/native-1.0.6.txt`, `tests/packaged-linux-1.0.6.txt`. Проверены 3/F, оба удара для каждого ножа, XInput2 и команды.
- Все 71 проверяемый файл в Linux/Windows ASAR совпадает с исходниками; никаких инъекций QA в поставке (`tests/package-integrity-1.0.6.txt`).
- AppImage извлечён: app.asar побайтово совпал с проверенным Linux-пакетом.
- NSIS: `Everything is Ok`, 81 файл, payload app.asar побайтово совпал с проверенным Windows-пакетом (`tests/installer-integrity-1.0.6.txt`). Это не нативный запуск Windows.

## Как повторить
- `npm ci`, `npm test`.
- В окружении с Playwright: `node tools/qa-v106-lab.cjs`; `CAPTURE_VIDEO=1` дополнительно пишет последовательность PNG в `previews/video106`.
- Linux/X11: поднять Xvfb на `:97`; запустить `tools/qa-v106-native.cjs` для настоящих нажатий 3/F, ЛКМ/ПКМ и регрессии команд. `tools/qa-v106-package.cjs` проверяет готовый Linux-клиент.
- `node tools/check-package-1.0.6.cjs` сравнивает файлы обоих ASAR с исходниками.

## Границы проверки
- Выборка вершин и контрольные объёмы — не непрерывная физическая симуляция и не проверка каждого контакта с пальцами. Контакт удерживаемой рукояти с пальцами намеренный.
- Linux проверяется под Xvfb/X11 с программным GPU, не на физической видеокарте или чистом Wayland. В тестовых запусках отключён watchdog программного GPU; первая параллельная с тяжёлым рендером попытка остановилась из-за потери WebGL-контекста. Это не доказательство ошибки драйвера на устройстве пользователя.
- Windows: сборка и статическая проверка содержимого; нативный запуск Windows в этом окружении недоступен.
