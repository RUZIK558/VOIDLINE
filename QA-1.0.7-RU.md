# Проверки VOIDLINE 1.0.7

- `tests/knife-reference-107.test.mjs`: отпечатки геометрии, индексов, материалов и локальных матриц старой бабочки совпадают с исходной моделью 1.0.4. Керамбит и его хват совпадают с 1.0.6. SHA-256 модуля `knife-motion.mjs` совпадает с одобренной версией 1.0.6.
- Проверка направления: продольная ось клинка имеет компонент Z меньше −0.85 (камера смотрит вдоль −Z), небольшой положительный Y; клинок направлен от игрока.
- `tools/qa-v107-lab.cjs`: оба ножа, оба осмотра, четыре типа движения, 160 временных отсчётов на клип. Проверяются вершины и сетка точек на треугольных поверхностях, а не только углы модели.
- Минимальный найденный зазор от бабочки до контрольного цилиндра предплечья: около 8.5 мм. Попаданий свободной рукояти/клинка в контрольный эллипсоид ладони не найдено. Это выборочная геометрическая проверка, не гарантия непрерывных столкновений всех пальцев.
- По 120 циклов прерывания на каждый нож, зеркальный хват: пересечений с контрольными областями и накопления смещения не найдено. Числовой отчёт: `tests/knife-clearance-1.0.7.json`.
- Кадры: `previews/1.0.7-*.png`; результаты полного прогона: `tests/regression-1.0.7.txt`.
- Linux runtime: `tools/qa-v107-native.cjs` (3/F, оба удара, команды); собранный пакет: `tools/qa-v107-package.cjs`; статическая сверка ASAR: `tools/check-package-1.0.7.cjs`.

## Финальные результаты
- Полный прогон: 217/217, без ошибок и пропусков.
- Linux-клиент и готовый пакет успешно запущены; проверки 3/F, обоих ударов, XInput2 и команд прошли (`tests/native-1.0.7.txt`, `tests/packaged-linux-1.0.7.txt`).
- В обоих ASAR все 71 выбранный файл совпали с исходниками, без инъекций QA. AppImage извлечён и совпал с проверенным Linux ASAR.
- NSIS: Everything is Ok; извлечённый app.asar побайтово совпал с проверенным Windows ASAR.

## Условия
Linux-тесты используют Xvfb/X11 и программный GPU с отключённым watchdog, не физическую видеокарту/мышь или чистый Wayland. Windows собирается и проверяется по содержимому; нативный запуск Windows в этом окружении недоступен.
