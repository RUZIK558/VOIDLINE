# Проверки VOIDLINE 1.0.2

## Что проверяется
- Регрессия: все старые тесты, а также реальные серверы WebSocket и P2P; новые проверки этажей и звука. Итоговый отчёт: tests/regression-final-1.0.2.txt.
- Лестницы: 16 верхних помещений × 2 независимых подхода, подъём и спуск с серверными коллизиями. Навигация к верхнему этажу и обратно на точку.
- Слои: проход под этажом, опора верхнего пола, прыжки, удары головой о перекрытие, падение с края, попадания пуль/гранат по плитам, запрет подбора сквозь потолок.
- КТ/Т: два сайта × восемь карт × пять стартовых позиций каждой роли, в обеих половинах матча.
- Баланс: 8-направленный Dijkstra с шагом 1 м и порталами лестничных переходов (учтены сокращения через верхние этажи), радиус игрока 0.36 м, промежуточные swept-проверки рёбер, одинаковая скорость 5.2 м/с; прибытие на границу зоны закладки. Это оценка проходимых маршрутов, не статистика побед и не гарантия при произвольных действиях игроков.
- Звук: 47 файлов PCM, 44.1 кГц / 16 бит, уникальные выстрелы и отсутствие цифрового клиппинга в сэмплах; направления, расстояния, укрытия, тихая ходьба и приседание.
- Настоящий Electron под Linux/Xvfb: декодирование всех 47 сэмплов, ненулевой выход аудиографа, воспроизведение, освобождение голосов и изменение громкости во время проигрывания. Проверяется цифровой выход, не субъективное качество на физических колонках/наушниках.
- Все восемь карт отрисованы настоящим WebGL-рендерером. PNG-снимки прямого framebuffer в previews/1.0.2-*.png.
- Linux XInput2 и закупка/чат повторно проверяются сохранённым нативным сценарием из 1.0.1, адаптированным к номеру версии.
- Windows: сборка и целостность архива; запуск на настоящей Windows здесь не проверялся.

## Повторяемость
npm ci
npm test
node tools/check-map-balance.mjs
npm run build:audio
npm run dist

Дополнительные QA-сценарии tools/qa-v102*.cjs требуют Playwright, GTK, Xvfb и xdotool. Их тестовые точки доступа внедряются только в ответы тестового браузера, в публичные игровые модули и сборки не включены.

## Ограничения
Чистый Wayland без XWayland, физические мыши, аудиоустройства и длительные матчи между разными компьютерами не проверены. Полный баланс побед требует живых матчей; геометрический приоритет КТ не исключает сильных позиций, которые проявятся в игре. Нельзя смешивать 1.0.2 с прежними версиями сервера: геометрия карт изменилась на обеих сторонах.
