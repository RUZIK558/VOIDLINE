# Проверки 1.0.9

- Полная регрессия: 238/238 тестов. В том числе 13 startup-тестов: отказ/зависание отдельного probe, общий HTTP-deadline при мелких порциях ответа, ограничение настоящей зависшей навигации, запрет внешнего origin, резервный и ручной экспорт журнала.
- Linux Electron из исходников: искусственный ERR_FAILED (-2) на первой навигации, затем восстановление; отдельный probe принудительно возвращает точную ошибку Local UI readiness timeout, но настоящее окно открывается. Настройки сохраняются.
- Готовая Linux-сборка до обновления видимой подписи версии: VSAC/VCAC, XInput2, управление, ножи, карты и все 47 звуков прошли проверку. После обновления подписи — отдельная проверка startup на финальном ASAR.
- Временный неисправный Chromium proxy не мешает изолированной DIRECT-сессии приложения.

Это воспроизведение механизма ошибки, не подтверждение первопричины сбоя на компьютере пользователя: предоставленный diagnostics.log содержал 0 байт. Linux тестируется через Xvfb/X11 и программный GPU, не на оборудовании пользователя. Нативный запуск Windows не проводится. Документированные ограничения VSAC/VCAC из ANTICHEAT-RU.md сохранены.

## Финальный Linux AppImage
- Финальный ASAR: 77 выбранных файлов совпали с исходниками; native helper/launcher совпали. ASAR из AppImage побайтово совпал с проверенной Linux-сборкой.
- VCAC проверил 147 файлов: clean. Пакетный startup-helper при принудительном Local UI readiness timeout открыл настоящий интерфейс с первой попытки.
- Журнал содержит boot и успешную навигацию, размер больше нуля. JavaScript-ошибок renderer нет; UI версии 1.0.9 просмотрен на отдельном снимке.
- В этом исправлении поставляются финальный Linux AppImage и исходники. Сборки Windows из промежуточного прогона не включены в выдачу.
