# VOIDLINE 1.0.0 — стабилизация

Релиз на основе предоставленных исходников 0.10.1. Обозначение 1.0.0 — номер этой сборки, не гарантия отсутствия любых ошибок.

## Изменения
- Во всех игровых надписях стороны обозначены Т / КТ; подписи и внешность соответствуют текущей стороне, в том числе после смены сторон. Внутренние имена DOM оставлены для совместимости.
- КТ: сине-серая форма, тёмная броня, широкий визор. Т: песочная форма, коричневая броня, шарф. Окраска рук и оружия не меняется вместе с общей формой.
- Добавлен LAN-поиск P2P-игроков: «Друзья и переписки → Найти игроков в LAN». После открытия P2P список обновляется автоматически. Выбери игрока, проверь его и нажми «Добавить»; второй игрок тоже должен добавить тебя. Автообнаружение не означает автоматическое доверие сертификату.
- Боты распределяются по ролям/точкам, используют разные приоритеты обхода, не все идут за носителем. Добавлены расталкивание в группе и перепрокладка пути при застревании.
- Мышь использует относительный Pointer Lock с запросом raw input и откатом на обычный захват, если raw input не поддерживается. Поворот по горизонтали не ограничен краями экрана; вертикальный предел расширен с ~80° до ~89°. Esc освобождает курсор. При отказе захвата игра не имитирует управление скрытием курсора.
- Исправлены линии живого предпросмотра прицела: позиционирование, видимость и изменение размеров.
- После смерти автоматически включается наблюдение за живым союзником от первого лица. ← / → или ЛКМ / ПКМ переключают союзника. Видны его оружие, патроны, здоровье, прицеливание, перезарядка и ослепление. Его модель скрыта перед камерой. После смерти/выхода союзника выбирается следующий; после возрождения возвращается собственная камера. Команды мёртвого игрока не меняют игровое состояние.
- Клиент и сервер используют общую проверку покупки. Для заблокированных предметов видна причина: сторона, уже купленное оружие, полный запас, бронежилет для шлема, лимит гранат, недостаток денег, зона/время закупки или ограничения ивента. Доступная AWP не означает, что можно купить АК за КТ или M4A1-S за Т: это правила стороны, а не цена.
- Вспышка выстрела привязана к точному дулу текущей модели; визуальные трассеры используют дуло оружия, включая сторонних игроков. Расчёт попадания остаётся серверным по направлению прицела, а не по клиентским визуальным эффектам.
- Усилен визуальный эффект близкой фронтальной флешки: короткая полная белая засветка с затуханием, стены блокируют эффект. Эффект получают и игроки, и боты; наблюдатель видит ослепление союзника.
- При новом раунде очищаются отложенные команды управления; выживший сохраняет оружие, боезапас, гранаты и броню. Сохраняется выбранное огнестрельное оружие. Добавлены регрессии переноса экипировки.

## Что считается нормальным сбросом
Смерть сбрасывает экипировку; оружие остаётся на земле текущего раунда. Смена сторон после шестого раунда сбрасывает экономику и экипировку. Новый матч также сбрасывает всё. Временное оружие ивента не переносится в обычный раунд. Это не удалено: иначе ломаются правила режима.

## Как играть вместе
Для матча хозяин создаёт игру и открывает LAN через Esc; второй игрок подключается к адресу матча. P2P-поиск обнаруживает пользователей для обмена кодами/переписки; это не глобальная очередь матчмейкинга и не NAT-релей.

Поиск LAN использует UDP multicast 239.255.86.76:3091, P2P — выбранный TCP-порт (по умолчанию 3090), матч — выбранный LAN-порт (по умолчанию 3080). Брандмауэр, изоляция Wi-Fi-клиентов и VPN без multicast могут блокировать поиск. Тогда используйте прежний обмен кодами/адресами. При закрытии P2P обнаружение прекращается.

## Проверки и ограничения
Результаты новых и существующих автоматических проверок, клиентских сценариев и сборки находятся в `QA-1.0-RU.md` и `tests/*1.0*`.
Фактический запуск Windows и работа на двух отдельных физических компьютерах требуют отдельного теста. Настоящий захват мыши в Wayland, конкретные драйверы GPU и интернет-маршрутизация не подтверждаются тестами headless Chromium. Подписанного сертификатом издателя Windows-инсталлятора нет.

## Запуск исходников
Требуется Node.js 22+ и npm: `npm ci`, затем `npm test` и `npm start`.
Для локального браузерного теста сервера: `npm run server`. Для упаковки: `npm run dist`.
