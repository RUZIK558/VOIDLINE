# VOIDLINE 1.0.9 — Startup Recovery

- Проверка HTTP-готовности больше не блокирует открытие интерфейса: отдельный запрос Node и загрузка Chromium выполняются независимо. Ошибка/зависание проверки записывается как предупреждение. Успех подтверждается настоящим документом игры, а не только ответом probe.
- Абсолютный срок HTTP-проверки — 5 секунд, даже если соединение понемногу отдаёт данные. Загрузка документа ограничена 60 секундами на попытку; проверка DOM — 15 секундами. Повторная загрузка остаётся ограниченной тремя попытками.
- До проверки целостности записывается boot-событие. При недоступности папки профиля журнал сохраняется в резервную папку VOIDLINE-diagnostics в системном temp. Если обе папки недоступны, последние события остаются в памяти для ручного сохранения.
- Диалог ошибки показывает фактический путь к журналу; кнопка открывает сам файл. Настройки, инвентарь и профиль не удаляются. VSAC/VCAC и исправление ножей сохранены; манифест пересоздан для версии 1.0.9.

Из предоставленного пустого diagnostics.log нельзя установить причину сбоя на конкретном компьютере. Воспроизведён и устранён механизм, при котором вспомогательная проверка препятствовала рабочей загрузке интерфейса. Это не утверждение об устранении любых ограничений loopback, внешних блокировок или сбоев GPU.
