# Проверки VOIDLINE 1.0.5

- tests/regression-1.0.5.txt — полный регрессионный прогон, включая шесть новых тестов загрузки.
- tests/startup-105.test.mjs — повтор ERR_FAILED, обработка ERR_ABORTED только с реально готовым интерфейсом, предел попыток, закрытое окно, настоящий HTTP probe, отказ для пустого/ошибочного HTML и внешнего адреса.
- tools/qa-v105-startup.cjs / tests/startup-native-1.0.5.txt — настоящий Electron под X11: запуск с заведомо нерабочим прокси, DIRECT в собственной сессии, принудительный обрыв первой загрузки документа с реальным ERR_FAILED (-2), повторная загрузка, сохранённые настройки.
- tools/qa-v105-visual.cjs / tests/visual-1.0.5.txt — новые Three.js-модели, фиксированные шарниры/кольцо, все четыре клипа, по 120 циклов прерывания без накопления смещения, компактные метки и меню при 1280×800 / 390×780. Кадры: previews/1.0.5-*.png.
- tools/qa-v105-native.cjs — настоящие нажатия 3/F, ЛКМ/ПКМ для обоих ножей, XInput2, V/СКМ и шесть фраз, отмена, ввод V в чате, TTL и недоставка противнику.
- tools/qa-v105-package.cjs — готовый Linux-пакет, нативный помощник из ASAR, новые модули ножей, компактные метки, восемь карт и 47 WAV. Содержимое Linux/Windows ASAR сравнивается с исходниками; AppImage и NSIS проверяются отдельно.

Ограничения: Windows собрана без нативного запуска на Windows. Linux QA использует Xvfb/X11, программный GPU, а не физическую мышь/видеокарту; чистый Wayland не проверен. Воспроизведён сам ERR_FAILED (-2), но точная причина на устройстве пользователя без diagnostics.log не установлена. Модели оригинальные, созданные по визуальным референсам; не импорт из присланных 3D-файлов.
