- `tests/vcac-108.test.mjs`: чистые файлы, изменение/удаление, испорченный манифест, недопустимые пути и внешние symlink, явно непроверенный режим разработки.
- `tools/qa-v108-lab.cjs`: клипы/поверхности/ладонь/предплечье, 120 циклов прерывания каждого ножа, отдельный снимок восстановленного idle после прерванного осмотра.

Linux использует Xvfb/X11, программный GPU с отключённым watchdog, а не физическую видеокарту/мышь или чистый Wayland. Windows собирается и проверяется статически, без нативного запуска. Выборочные геометрические проверки не являются непрерывным физическим контактом каждого пальца. Полная модель ограничений античита: ANTICHEAT-RU.md.

## Результаты
- Полный `npm test`: 231/231, ошибок 0. Повторный отдельный прогон 14 новых тестов — 14/14.
- Геометрическая лаборатория: 160 отсчётов на клип, оба варианта осмотра, 120 циклов прерывания, зеркальная рука; выборочных пересечений ладони/предплечья не найдено.
- Снимки idle после прерывания побайтово совпали с каноническими idle для бабочки и керамбита.
- Linux Electron из исходников: реальные F/ЛКМ/ПКМ, завершение до idle, тактические команды; у честного клиента ноль отклонённых пакетов, VCAC-отчёт доставлен. Визуальные состояния ножей проверены по отдельным PNG.
- Две ASAR-сборки: 76 выбранных файлов каждой совпадают с исходниками; тестовых hooks в игровом коде нет.

На программном GPU тест завершения ждёт состояние idle, а не фиксированную секунду: игровой delta ограничен 50 мс/кадр, при низком FPS клип занимает больше реального времени.
- Готовый Linux-пакет: VCAC clean, 146 файлов; обычные пакеты не отклоняются, отчёты доставляются в VSAC. Нативный ввод, обе модели, карты и все 47 звуков прошли проверку. Статусы VSAC/VCAC видны в паузе.
- Извлечённый Windows ASAR: VCAC clean, 146 файлов. Встроенный ASAR установщика NSIS и portable совпал с проверенным Windows-пакетом; оба архива прошли `7zz t`.
- ASAR из AppImage совпал с проверенным Linux-пакетом. Windows-исполнение не проводилось; релиз без подписи Windows/криптографической аттестации.
